# 线上体验

打开[今天吃什么](https://wantingworking-oss.github.io/food-assistant-demo/)，点击“进入今天吃什么”。

1. 点击小A已有要求下方的“调整本餐要求”，再展开弹窗内的“AI服务访问码”，填写体验提供者给你的访问码，点击“保存访问码”。项目所有者可从本机私有文件“体验访问码.txt”复制；该文件不上传GitHub。
2. 输入“这餐偏好面食，不吃鸡肉”，点击“理解并填入草稿”。也可直接手动勾选；核对“本次将修改”，点击“应用修改”后查看更新的摘要与推荐。
3. 点击“选这餐”，核对费用和规格，再“确认并模拟提交”。不会产生真实订单或支付。
4. 试试“这顿花生可以，长期不改”：先写入草稿，点击“应用修改”并确认后才应用本次例外，长期要求保留。取消和Esc关闭均不应用待确认变更。

使用AI会消耗所有者的DeepSeek API余额。访问码只在当前标签页保存，关闭后可能需要重新填写；不要把模型API Key填在这里。

Render免费后端休眠后，首次访问可能需要约一分钟启动；超时时等待后重试。手动编辑和模拟下单不依赖AI，也可直接使用。

这是模拟选餐体验，支持示例用户、偏好/历史编辑、加菜、撤销、刷新恢复和模拟供给变化；没有真实商家下单、支付、账户或跨设备同步。

取消、关闭或按Esc会丢弃尚未应用的草稿。输入支持主食、口味、份量与忌口调整，暂不支持“想吃炒鸡”等按菜名检索。历史备注整理在“核对历史”面板中。
