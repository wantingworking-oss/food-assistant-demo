# 线上体验

打开[今天吃什么](https://wantingworking-oss.github.io/food-assistant-demo/)，点击“进入今天吃什么”。

1. 展开“AI服务访问码”，填写体验提供者给你的访问码，点击“保存访问码”。项目所有者可从本机私有文件“体验访问码.txt”复制；该文件不上传GitHub。
2. 输入“今天想吃面，不要鸡肉”，点击“理解并应用”，查看本餐要求及推荐。
3. 点击“选这餐”，核对费用和规格，再“确认并模拟提交”。不会产生真实订单或支付。
4. 试试“这顿花生可以，长期不改”：只有确认后才应用本次例外，长期要求保留。取消和Esc关闭均不应用待确认变更。

使用AI会消耗所有者的DeepSeek API余额。访问码只在当前标签页保存，关闭后可能需要重新填写；不要把模型API Key填在这里。

Render免费后端休眠后，首次访问可能需要约一分钟启动；超时时等待后重试。手动编辑和模拟下单不依赖AI，也可直接使用。

这是模拟选餐体验，支持示例用户、偏好/历史编辑、加菜、撤销、刷新恢复和模拟供给变化；没有真实商家下单、支付、账户或跨设备同步。
